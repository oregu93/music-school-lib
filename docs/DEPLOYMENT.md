# Развёртывание

## Закрытый Sites

Текущий сайт публикуется из этого проекта как закрытый. Код отправляется в служебный репозиторий, миграции из `drizzle/` применяются автоматически. Файлы Excel в публикацию не входят.

Для выпуска новой версии попросите Codex проверить сборку и опубликовать текущий проект. Доступ другим сотрудникам добавляется отдельно; сам факт публикации не делает сайт общедоступным.

## GitHub

Создайте пустой закрытый репозиторий и отправьте папку проекта:

```powershell
git remote add origin https://github.com/USER/library-catalog.git
git push -u origin main
```

Перед отправкой выполните `git status` и убедитесь, что нет `.env`, Excel, подготовленного SQL и иных данных библиотеки. Эти файлы исключены через `.gitignore`.

## Самостоятельный Cloudflare Worker

1. Установите Node.js 22 и pnpm.
2. Выполните `pnpm install` и `pnpm build`.
3. Создайте D1-базу в своей учётной записи Cloudflare.
4. В рабочей конфигурации Wrangler замените тестовый идентификатор D1 на идентификатор созданной базы, сохранив binding `DB`.
5. Примените `drizzle/0000_chunky_mauler.sql` к D1.
6. Задайте переменные из `.env.example` как серверные настройки/секреты.
7. Разверните Worker и проверьте вход, поиск, изменение карточки и журнал действий.

Производственный домен и callback OAuth должны использовать HTTPS. Секреты нельзя записывать в репозиторий или передавать в адресной строке.
