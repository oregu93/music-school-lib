# Состояние разработки

Обновлено: 12 сентября 2026 года.

## Готово

- Создан адаптивный веб-интерфейс каталога с поиском и фильтрами.
- Строка списка открывает карточку экземпляра.
- Поля подписаны как «Инвентарный номер» и «№ записи в БД».
- В карточке можно редактировать сведения; справа формируется настоящий QR-код.
- Реализованы отметка «Проверено», восстановимое удаление и корзина.
- Реализованы выдача, возврат, индикатор наличия и журнал операций по экземпляру.
- Подготовлена серверная база D1 для всех 36 полей исходного каталога, выдач и журнала действий.
- Интерфейс подключён к API сохранения, добавления, проверки, удаления и восстановления.
- Добавлен безопасный локальный демонстрационный режим без загрузки рабочего Excel.
- Проект трижды успешно прошёл производственную сборку после добавления API.
