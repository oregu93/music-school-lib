# Электронный каталог музыкальной школы

Веб-интерфейс для поиска и редактирования экземпляров библиотечного фонда. Исходный Excel остаётся резервным источником, рабочие изменения хранятся в серверной базе SQLite/D1.

## Возможности

- поиск по автору, заглавию и номерам;
- карточка экземпляра с QR-кодом;
- редактирование и добавление экземпляра;
- установка и снятие отметки «Проверено»;
- восстановимое удаление;
- журнал действий пользователей;
- выгрузка каталога в CSV.

## Структура

- `app/catalog-client.tsx` — пользовательский интерфейс;
- `app/api/` — серверные операции каталога;
- `db/schema.ts` — структура базы;
- `drizzle/` — миграции базы;
- `scripts/catalog_to_sql.py` — локальная проверка Excel и подготовка импорта;
- `docs/` — инструкции по архитектуре, развёртыванию, импорту и OAuth.

## Локальный запуск

```powershell
pnpm install
pnpm dev
```

Откройте `http://localhost:3000`. Без серверной авторизации включается демонстрационный режим; реальные данные в браузере не сохраняются.

Подробности: [развёртывание](docs/DEPLOYMENT.md), [импорт](docs/IMPORT.md), [OAuth](docs/OAUTH.md), [архитектура](docs/ARCHITECTURE.md).
